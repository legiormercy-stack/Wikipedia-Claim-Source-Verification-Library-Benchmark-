# Decision	Reason

1. If a cited source does not support the claim, the claim should not be labelled supported merely because a source is cited.
2. If a source is inaccessible, the claim should not automatically be labelled refuted.
3. If a claim is only partially supported, record the degree of support and apply the defined label.
4. If the source contains evidence that contradicts the claim, record the contradiction and apply the defined label.
